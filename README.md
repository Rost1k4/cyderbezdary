# Dota 2 Tournament Manager (ФТІ КПІ)

Сайт турніру з Dota 2: сітка double elimination на 4 або 8 команд, таблиця, журнал матчів,
статистика матчу за Match ID (OpenDota) і коротка AI-оцінка гри (Google Gemini).
Результати вносить лише організатор за паролем.

## Що в репозиторії

| Файл | Призначення |
|---|---|
| `app.py` | Сайт (Streamlit). На хмарі запускається саме він |
| `storage.py` | Збереження даних: PostgreSQL у хмарі, SQLite локально |
| `tournament.py` | Логіка сітки |
| `ai_review.py`, `config.py` | AI-оцінка (Gemini) |
| `opendota.py`, `matchview.py`, `bracket_html.py` | Дані матчів і малювання сітки |
| `main.py`, `cli.py` | Локальний запуск сайту / консольна версія |
| `.streamlit/config.toml` | Тема сайту |
| `.streamlit/secrets.toml.example` | Приклад секретів (справжні значення в репозиторій НЕ потрапляють) |

## Публікація: покроково

### 1. База даних (безкоштовно, 5 хвилин)

Streamlit Cloud не зберігає файли між перезапусками, тому без зовнішньої бази дані турніру
можуть зникнути. Створіть безкоштовну PostgreSQL:

1. Зареєструйтесь на [neon.tech](https://neon.tech) і створіть проєкт.
2. Скопіюйте **Connection string**. Він виглядає так:
   `postgresql://користувач:пароль@ep-xxxx-pooler.регіон.aws.neon.tech/neondb?sslmode=require`
3. Збережіть його, він знадобиться в кроці 3.

Таблиці створюються автоматично при першому запуску сайту.

> Supabase теж підійде, але беріть рядок **Session pooler**: прямий хост у Supabase працює
> лише через IPv6, і Streamlit Cloud до нього може не підключитися.

### 2. GitHub

1. Створіть **публічний** репозиторій на GitHub.
2. Завантажте в нього всі файли цієї папки (разом із `.gitignore` та папкою `.streamlit`).
3. Перевірте, що в репозиторії **немає** `tournament.db`, `config_local.py` і
   `.streamlit/secrets.toml`. Вони у `.gitignore`, тож не мають потрапити.

### 3. Streamlit Community Cloud

1. Зайдіть на [share.streamlit.io](https://share.streamlit.io) і увійдіть через GitHub.
2. **Create app** -> оберіть свій репозиторій і гілку `main`.
3. **Main file path:** `app.py` (не `main.py`).
4. **Advanced settings:** Python версії 3.12 (або 3.11), у полі **Secrets** вставте:

   ```toml
   admin_password = "ваш-довгий-пароль"
   database_url = "рядок-підключення-з-кроку-1"
   gemini_api_key = "ключ-з-aistudio.google.com/apikey"
   ```
5. Натисніть **Deploy**. Перша збірка займає кілька хвилин.

Секрети можна змінити пізніше: **Manage app -> Settings -> Secrets**.

### 4. Перевірка після запуску

1. Відкрийте сайт, у бічній панелі увійдіть паролем організатора.
2. Угорі бічної панелі має бути напис **«Сховище: PostgreSQL»**. Якщо там жовте повідомлення про
   локальний файл, значить `database_url` не підхопився. Перевірте Secrets.
3. Додайте команди, запустіть турнір, внесіть тестовий результат.
4. Натисніть **Reboot app** у Manage app: команди й результати мають залишитися.
5. Скиньте тестові дані кнопкою «Скинути турнір».

## У день турніру

* Безкоштовний застосунок засинає після ~12 годин без відвідувань. Дані при цьому цілі
  (вони в Neon), але прокидання займає хвилину. Відкрийте сайт за годину до початку.
* Match ID беріть з історії матчів Dota 2, а не ID лобі. У гравців має бути увімкнено
  «Журнал матчів доступний усім».
* OpenDota інколи розбирає матч із затримкою. Кнопка «Запросити розбір в OpenDota» на сайті
  допомагає.
* Ліміт запитів Gemini безкоштовний, тому AI-оцінка кешується на годину для кожного матчу.

## Якщо щось не працює

| Симптом | Що робити |
|---|---|
| «Не вдалося підключитися до бази даних» | Перевірте `database_url` у Secrets: має бути повний рядок із `?sslmode=require` |
| Немає входу організатора | У Secrets не задано `admin_password` |
| AI: «Не задано ключ Gemini» | Додайте `gemini_api_key` у Secrets |
| AI: «перевантажена», «ліміт» або таймаут | Зачекайте хвилину. Якщо повторюється, додайте в Secrets `gemini_model = "gemini-flash-lite-latest"` (швидша й легша модель) і натисніть Reboot app |
| «Матч не знайдено» | Це не Match ID або матч ще не з'явився в OpenDota |

## Локальний запуск

```bash
pip install -r requirements.txt
python main.py
```

Без `database_url` дані зберігаються у файлі `tournament.db`. Ключі можна задати змінними
середовища (`GEMINI_API_KEY`, `TOURNAMENT_ADMIN_PASSWORD`, `DATABASE_URL`) або файлом
`.streamlit/secrets.toml` за зразком `secrets.toml.example`.

Консольна версія одного матчу: `python cli.py`.
